# Vantelyx CLM Brand System

## Locked Product Name

**Vantelyx CLM**

Use this exact name across the application, proposal material, screenshots, demos, documentation, API service descriptions, and sales collateral.

## Positioning

Vantelyx CLM is an AI-powered contract lifecycle and obligation intelligence platform designed for organizations that need stronger control over intake, approvals, renewals, risk, compliance, vendor obligations, and audit readiness.

## Short Description

Vantelyx CLM turns contracts into an active command center where every agreement has a clear owner, status, risk score, renewal clock, obligations, approvals, and evidence trail.

## UI Naming Rules

- Product name: **Vantelyx CLM**
- Sidebar/product label: **Vantelyx CLM**
- Suite label: **Contract Intelligence Suite**
- API service name: **vantelyx-clm-api**
- Web service name: **vantelyx-clm-web**
- Database name: **vantelyx_clm**
- Docker project services: use the `vantelyx-clm-*` naming pattern

## Messaging Pillars

1. **Command Center, not repository** — contracts are managed as live business objects, not passive files.
2. **Obligations become accountable work** — commitments, dates, owners, and evidence are tracked clearly.
3. **Risk is visible early** — AI-assisted clause review, renewal risk, compliance flags, and approval routing are surfaced before execution.
4. **RFP-ready governance** — audit trails, role-based access, configurable workflows, reporting, and retention controls support enterprise and public-sector buying requirements.
5. **Low-training user experience** — dashboard-first design, clear CTAs, guided intake, and plain-English summaries reduce adoption friction.
